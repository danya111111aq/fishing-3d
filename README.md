# Рыбалка 3D — браузерный прототип

Первая версия 3D-рыбалки от первого лица на Three.js. Весь игровой код находится в `index.html`, `style.css` и `game.js`; внешний файл фонового изображения не нужен — озеро, вода, берег, горы, лес, док, удочка, рука и рыбы создаются геометрией и материалами в Three.js.

## Запуск

Three.js загружается с jsDelivr, поэтому при первом запуске нужен интернет.

**Вариант 1 — VS Code:** установи расширение Live Server, открой папку и запусти `index.html` через Live Server.

**Вариант 2 — Python:** открой терминал в папке проекта и выполни:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000` в браузере.

Не открывай `index.html` как `file://`: браузер обычно блокирует ES-модули при таком способе запуска.

## Управление

- **Провести по экрану / мышью:** повернуть камеру.
- **Выбрать место:** нажать «Выбрать место», затем коснуться воды.
- **Забросить:** выбрать силу и нажать «Забросить»; на телефоне также можно провести вверх.
- **Подсечь:** нажать кнопку при поклёвке.
- **Выловить:** появляется после того, как рыба устанет.
- **Садок:** посмотреть улов и продать рыбу.

## Физика и графика

Заброс использует кинематическую траекторию с ускорением свободного падения: горизонтальная скорость зависит от силы и дальности, время полёта рассчитывается из дальности, а начальная вертикальная скорость подбирается так, чтобы поплавок пришёл в выбранную точку. Леска пересчитывается каждый кадр и провисает по дуге. Вода использует собственный GLSL-шейдер с волнами, бликами и отражающим Fresnel-эффектом. Берег и рыбы — процедурные 3D-модели.

Это самостоятельный игровой прототип, а не законченная коммерческая игра: вода использует стилизованный шейдер, не физически точное трассирование лучей; рыбы и руки пока простые процедурные модели. Для настоящего AAA-визуала потребуются качественные лицензированные модели, текстуры и дополнительные эффекты.

## Управление на телефоне

- **Повернуть обзор:** проведи одним пальцем по сцене влево/вправо или вверх/вниз.
- **Забросить жестом:** быстро проведи пальцем вверх по сцене. Чем длиннее свайп, тем сильнее бросок; ползунок силы тоже работает.
- **Забросить кнопкой:** нажми «Забросить».
- **Выбрать место:** нажми «Выбрать место», затем коснись поверхности воды.
- **Подсечь / выловить:** нажимай большие экранные кнопки внизу.
- Интерфейс учитывает вырезы экрана и системные отступы телефона; поверни устройство горизонтально, если хочешь больше пространства.

## Открыть игру на телефоне

Самый простой способ — опубликовать папку на статическом хостинге (например, GitHub Pages или Netlify), а затем открыть выданную HTTPS-ссылку в браузере телефона. Так как Three.js загружается как ES-модуль с CDN, простое открытие `index.html` из файлового менеджера может не работать.

Для теста на компьютере и телефоне в одной Wi‑Fi сети можно запустить `python -m http.server 8000`, узнать локальный IP компьютера и открыть на телефоне `http://IP-КОМПЬЮТЕРА:8000` при условии, что брандмауэр разрешает подключение. Для постоянной ссылки нужен хостинг; этот архив сам по себе не публикует игру в интернете.
