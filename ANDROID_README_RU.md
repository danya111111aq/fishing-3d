# Рыбалка 3D — сборка APK через Android-only workflow

Этот пакет содержит исходный код браузерной игры и GitHub Actions workflow, который соберёт Android APK в облаке. В этом архиве самого APK пока нет.

## Как собрать APK только с телефона

1. Распакуйте архив (или загрузите файлы репозитория на GitHub).
2. Создайте **Public** репозиторий на https://github.com/new.
3. Загрузите все файлы и папки из этого проекта в корень репозитория, включая скрытую папку `.github/workflows`.
4. Откройте вкладку **Actions** в репозитории. Если попросит, нажмите **I understand my workflows, go ahead and enable them**.
5. Запустите workflow **Build Android APK** через **Run workflow**, либо дождитесь сборки после загрузки файлов.
6. Откройте завершённый запуск workflow, прокрутите до **Artifacts** и скачайте `fishing-3d-debug-apk`.
7. Распакуйте загруженный artifact ZIP и установите `app-debug.apk` на Android. При запросе Android может попросить разрешить установку из этого источника.

## Важно

- Это **debug APK** для тестирования, не подписанная версия для Google Play.
- Игра использует Three.js с CDN, поэтому для загрузки библиотеки и работы игры требуется интернет.
- Для сборки нужен интернет, а также GitHub-аккаунт.
- Не публикуйте в репозитории пароли, ключи или личные данные.
